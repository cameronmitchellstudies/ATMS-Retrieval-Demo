02 · Retrieval Pipeline

From raw brightness temperatures to stability indices

The pipeline processes NOAA NODD BUFR files in near-real-time, ingesting 22-channel ATMS microwave brightness temperatures and producing gridded atmospheric profiles and instability indices within minutes of data availability.

01
BUFR Ingestion from NOAA NODD
Paginated S3 listing downloads all ~2,700 BUFR granule files for the target date. Each file covers ~18 seconds of observation, parsed in parallel to extract lat/lon, zenith angle, and 22-channel antenna brightness temperatures.
2,700 files · 290 MB
02
ERA5 Surface Field Interpolation
ERA5 reanalysis surface pressure and land-sea mask are interpolated bilinearly to each satellite FOV position and linearly in time using the exact observation timestamp parsed from each BUFR filename.
Hourly · 0.25° ERA5
03
MLP Temperature & Water Vapor Retrieval
25-feature input vectors [BT×22, sec(zen)−1, land flag, surf pressure] are fed to two sklearn MLPs trained on 53M collocated ATMS+ERA5 samples. Water vapor uses a hybrid approach — linear g/kg below 600 hPa, log-space model above for improved upper-troposphere accuracy.
37 T levels · 27 WV levels
04
T2/D2/Surface Pressure Retrieval
A dedicated MLP retrieves 2-metre temperature, 2-metre dewpoint, and surface pressure using terrain height as the surface predictor instead of ERA5 pressure — enabling surface parcel calculations for CAPE and LI.
Required for CAPE · LI · CIN
05
Stability Index Computation
Full thermodynamic stability indices computed per FOV using Bolton (1980) parcel physics: LCL, moist adiabatic ascent, LFC detection, and trapezoidal CAPE/CIN integration in log-pressure coordinates.
KI · TT · LI · SI · CAPE · CIN · TPW
06
Per-Pass Gridding & Output
Each orbital pass is gridded separately at 0.25° using Delaunay triangulation with maximum edge length filtering to prevent gap interpolation. Results saved as georeferenced PNGs and NPZ arrays.
0.25° grid · Delaunay masked

Operational Use Case

In an operational setting, this pipeline would run automatically within minutes of data availability on NOAA NODD. Emergency managers and NWS forecasters would receive automated alerts when any monitored region exceeds instability thresholds — providing
~3–4 hours of additional lead time beyond conventional surface observation networks, derived entirely from satellite-based microwave soundings at 50 km resolution.
